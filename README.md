# Music Hub — музыка из VK и YouTube в одном окне

Настольное приложение (PySide6) для Windows. Идея простая: **музыка живёт в VK**, а YouTube и
другие источники — место, где её слушают и находят. Понравился трек — одна кнопка «+ VK», и он
навсегда в вашей музыке VK. Скачивание видео и MP3 никуда не делось — это отдельный раздел.

## Что умеет

- **Играть** — сквозной плеер: полоса управления внизу видна на любой вкладке, музыка не
  прерывается при переходе между разделами. VK и локальные файлы играют встроенным
  проигрывателем, YouTube — во встроенной странице YouTube.
- **Кнопка «+ VK»** — переносит трек в «Мою музыку» VK. Сначала ищет там же готовую запись и
  добавляет её (мгновенно, без трафика); если подходящей нет — скачивает звук и заливает файл.
  Уже перенесённые треки помечены «✓ В VK» и после перезапуска тоже.
- **Разделы**: Главная (что играет, продолжение очереди, недавнее и подборки), YouTube
  (поиск и рекомендации), Музыка VK (своя музыка и поиск по всему VK), Плейлисты (свои,
  VK и YouTube), Избранное, История, Загрузки, Библиотека (файлы на диске).
- **Очередь проигрывания** — панель справа, отдельная от очереди загрузок: «Играть»,
  «В очередь», «Играть следующим», перетаскивание, перемешивание и повтор.
- **Рекомендации и радио** — лента YouTube Music по вашей учётной записи в браузере, радио по
  треку и по исполнителю, автопродолжение: когда очередь подходит к концу, похожее дописывается
  само. Если рекомендации недоступны, приложение честно говорит, что показывает поиск, а не
  подборку.
- **Видео или только звук** — режим переключается на ходу и не перезапускает трек: «только
  звук» прячет видео, «видео» показывает кадр 16:9, двойной щелчок разворачивает на весь экран.
- **Продолжить с того же места** — очередь, трек, позиция, громкость и режимы сохраняются между
  запусками; после старта музыка ждёт вашего нажатия, а не включается сама.
- **Поиск везде (Ctrl+K)** — по VK, YouTube и своей библиотеке сразу.
- **Мини-плеер** — маленькое окно поверх остальных программ; главное окно при этом не закрывается.
- **История прослушиваний** — по дням, с действиями «играть», «+ VK», «в избранное», «радио».
  Случайно задетый трек в историю не попадает: считается прослушивание дольше 30 секунд.
- **Значок в трее** — управление и сведения о треке, окно можно сворачивать и закрывать в трей.
- **Глобальные сочетания клавиш** — плей/пауза, следующий, предыдущий, «в избранное», «+ VK»,
  показать окно; работают и когда окно свёрнуто. Поддержаны мультимедийные клавиши.
- **Расширение для браузера** (`browser_extension/`) — отправить ссылку с YouTube или VK прямо
  в приложение: играть, в очередь, добавить в VK.
- **Загрузчик как раньше**: видео и плейлисты YouTube в MP4, музыка в MP3/M4A/Opus/FLAC,
  видео VK, личная музыка и плейлисты VK.

## Установка

### Готовая сборка (проще всего)

Скачайте `MusicHub-portable.zip` со страницы [Releases](../../releases), распакуйте в любую
папку и запустите `MusicHub.exe`. Устанавливать ничего не нужно: Python, ffmpeg и движок JS
уже внутри.

Программа переносимая — музыка, настройки и журналы складываются рядом с `MusicHub.exe`,
поэтому папку можно целиком унести на флешке вместе со всем нажитым.

### Из исходников

Нужен [Python 3.12+](https://www.python.org/downloads/). Дважды кликните `run.bat` — при первом
запуске он создаст виртуальное окружение `.venv`, поставит зависимости из `requirements.txt`
и запустит приложение.

Двух сторонних программ в репозитории нет, они слишком тяжёлые:

- **ffmpeg** — нужен для скачивания и конвертации. Возьмите сборку для Windows
  (например, [gyan.dev](https://www.gyan.dev/ffmpeg/builds/)) и положите `ffmpeg.exe`
  в `ffmpeg/bin/`.
- **Движок JavaScript** — без него YouTube не отдаёт ссылки на потоки. Проще всего:
  Настройки → «Аккаунты» → «Скачать движок», приложение заберёт QuickJS само (≈2 МБ).

## Вход в VK

Нажмите значок VK в правом верхнем углу окна — он же показывает состояние входа. Открывается
настоящая страница входа VK, пароль нигде не сохраняется: сохраняются токен доступа
(`config/vk_token.json`) и куки сессии, нужные для списка треков.

Уже вошли — тот же значок открывает Настройки → «Аккаунты», где живут «Сменить аккаунт»
и «Выйти». Значок YouTube рядом ведёт туда же и показывает, на месте ли движок JS.

## Расширение для браузера

1. Настройки → «Музыка и связь» → «Мост для расширения»: включите мост и нажмите «Показать»,
   чтобы увидеть ключ.
2. В Chrome/Edge откройте `chrome://extensions`, включите «Режим разработчика» →
   «Загрузить распакованное расширение» → папка `browser_extension`.
3. В настройках расширения вставьте ключ и порт (по умолчанию 48211).

Приложение слушает только `127.0.0.1` и только с этим ключом; расширение умеет лишь прислать
ссылку — доступа к вашему аккаунту VK у него нет.

## Настройки

- **Загрузки** — формат, качество, папки, куки, прокси, движок JS для YouTube.
- **Музыка и связь** — громкость, автопереход к следующему треку, поведение кнопки «+ VK»
  (искать ли в VK перед заливкой, спрашивать ли при нескольких похожих записях), трей,
  сочетания клавиш, мост для расширения.
- **Аккаунты** — вход в VK, движок JS для YouTube, куки браузера.

Старые настройки прошлых версий читаются как есть: недостающие ключи просто добавляются.

## Устройство проекта

- `app/main.py` — точка входа.
- `app/config.py` — пути (`музыка/`, `видео/`, `logs/`, `config/`) и настройки.
- `app/core/` — логика: yt-dlp (YouTube и видео VK), VK-музыка, очередь загрузок и заливки,
  плеер, перенос в VK, локальная база (`config/musichub.db`), мост для расширения.
- `app/ui/` — окна и виджеты PySide6.
- `browser_extension/` — расширение MV3 для Chromium.
- `tests/` — тесты: `.venv\Scripts\python.exe -m unittest discover -s tests -t .`
  (сеть и VK не трогаются).
- `docs/android_plan.md` — что и как переносится на Android.
- `ffmpeg/bin/ffmpeg.exe` — конвертация аудио/видео (в репозиторий не входит, см. «Установка»).
- `MusicHub.spec` — описание сборки переносимой версии.
- `cookies.txt` — опционально, для приватных/18+ видео YouTube.

## Чего приложение не делает

- Не удаляет вашу музыку из VK: метод удаления аудио этому токену недоступен, поэтому
  залитое убирается только вручную в VK.
- Не хранит копию всей фонотеки VK на диске — VK и есть хранилище.
- Не подключает Яндекс.Музыку: публичного API нет, а обходить защиту сервиса приложение не будет.
- Не хранит пароль от Google: рекомендации YouTube работают на тех же куках браузера, что и
  загрузчик. Нет кук — рекомендации будут гостевыми, всё остальное работает как прежде.
- Не показывает тексты песен: подходящего источника нет, а придумывать их приложение не станет.

## Сборка переносимой версии

```
.venv\Scripts\python.exe -m pip install pyinstaller
.venv\Scripts\python.exe -m PyInstaller MusicHub.spec --noconfirm
```

Готовое лежит в `dist/MusicHub/`. Всё, что найдётся в `ffmpeg/bin/` и `runtime/`, попадает
внутрь сборки; чего нет — просто не попадёт, и приложение потом предложит скачать движок само.
